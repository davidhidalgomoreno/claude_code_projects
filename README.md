# COEUS · Sistema de generación de ángulos

Motor de ángulos de anuncio para suplementación de longevidad y retroaging.
Cliente: COEUS Retroaging. Agencia: Chinxy.

El sistema vive como skill de Claude Code en
[`.claude/skills/coeus-angles/`](.claude/skills/coeus-angles/SKILL.md).

## Qué resuelve

Genera ángulos de anuncio con hook y brief de rodaje, etiquetados con una
taxonomía que permite cruzar rendimiento real de Meta contra palanca
psicológica — y no contra el nombre del archivo.

## Aviso

Categoría regulada. Las declaraciones de propiedades saludables de complementos
alimenticios en la UE se rigen por el Reglamento (CE) 1924/2006 y los botánicos
siguen pendientes de resolución. Nada generado por este sistema se publica sin
pasar la compuerta de cumplimiento y revisión humana.
